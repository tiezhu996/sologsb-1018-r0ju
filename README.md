# 声律场 · 口语发音与韵律练习工作台

使用 Svelte 与 Skeleton 从零实现的口语练习工作台。学习者可以录入句子、划分意群并标注重音、停顿和语调，随后录音、选择回听范围、逐段比较偏差；教师反馈与错词分类会和具体尝试、意群绑定。

## 功能

- 句子录入、标点智能切分、意群增删与排序。
- 逐意群标注重音词、重音强度、停顿毫秒数和语调走向。
- 调用浏览器麦克风录音，支持多轮尝试；未授权麦克风时保留可校对的离线模拟轮次。
- 每一轮尝试独立保存回听起点、终点、准确度、节奏、偏差、自评和错词分类。
- 每轮录音按轮独立存入 IndexedDB 音频区，练习主体只保存标注、评分和录音索引；单轮写入失败只影响这一轮（仍可校对，标明无法回听），不牵连其他录音。
- 移除一轮会删除该轮音频，其评分、错词和反馈同步退出进度统计；撤销后整轮（含录音）一起恢复。
- 旧版整包数据首次打开时自动拆分到新结构。
- 教师可按意群留下多轮反馈。
- 练习进度、目标轮次、准确度、偏差和错词分类统计。
- 使用 IndexedDB 持久化录音和全部标注，网络中断时继续编辑，不会因刷新丢失。
- Service Worker 缓存应用壳，已打开的生产页面可离线访问。
- 响应式手机/桌面布局和键盘工作流。

## 技术栈

- Svelte 4
- Vite 5
- TypeScript
- Skeleton 2
- Tailwind CSS 3

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器使用本地端口 `5175`，该端口不构成宿主映射。容器生产环境仅监听 `80`。

## 生产构建

```bash
npm install
npm run build
npm run preview
```

构建结果位于 `dist/`。

## Docker

```bash
docker build -t sologsb-1018 .
docker run --rm -p 10018:80 sologsb-1018
```

最终镜像使用 nginx 在容器 `80` 端口提供构建产物。宿主端口由根编排文件维护，源码和 Dockerfile 没有硬编码宿主端口。

## 本地数据与麦克风

- 录音 Blob 按轮独立存放在 IndexedDB 音频存储区；练习主体（句子、意群标注、评分、错词、反馈）单独存放，只保留每轮录音的索引。
- IndexedDB 不可用时会退化为 `localStorage`，但浏览器安全限制下不保存原始录音 Blob，受影响轮次会标明“无法回听”，标注仍可编辑。
- 麦克风从未上传到服务器；清除站点数据会永久删除本机练习。
- 生产页面首次加载后由 Service Worker 缓存，离线状态仍可继续标注和录音。
